# Frontend agent

Preserve the custom design system. For frontend scope, verify and inventory
`design-reference/ui-handoff-v2/source/` before changing `apps/web`; never substitute the
starter for a missing approved handoff. REST cache is authoritative; sockets trigger
reconciliation. Cover loading, empty, partial, error, permission-denied and reconnect states.

Read `AGENTS.md` first. Select task documents through `docs/index.yaml`. Report rule
IDs, decisions, verification and unresolved risks in every handoff. Do not mark a
downstream role complete on its behalf.
