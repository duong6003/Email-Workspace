The current Mailcraft prototype can be reviewed at:

https://email-operations-workspace.alta-softwar-9113.chatgpt.site

Use this prototype to compare the written UI handoff with the current interaction direction. It is a visual reference, not the EOW production implementation.

## Review notes

The EOW team should review the prototype against the UI handoff and decide:

- which EOW shell components are reused;
- which Mailcraft visual tokens remain independent;
- whether focus mode should hide the EOW sidebar;
- how the provider/identity administration surfaces fit the existing EOW settings;
- which interactions must be keyboard-accessible before implementation.

The production implementation should follow the package boundaries in COMPONENT-CONTRACTS.md rather than copying prototype internals into EOW.
